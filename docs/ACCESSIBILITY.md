# Accessibility notes

The interface uses semantic buttons, form labels, visible keyboard focus, and a reduced-motion check for the entry animation. The security test results use status and alert semantics, and trust controls have explicit labels.

This project has not completed a formal WCAG conformance audit. Keyboard navigation, screen-reader output, contrast, zoom/reflow, and mobile interaction should be reviewed before making an accessibility conformance claim. Report specific barriers through the repository maintainer.
