# Third-party services and data flows

Open Door does not use advertising pixels, analytics SDKs, or payment processors.

| Service | When used | Data sent or exposed | Current boundary |
| --- | --- | --- | --- |
| Replit-managed Clerk | Optional account sign-in and session management | Account identity fields entered into the sign-in UI and authentication/session metadata. Clerk telemetry is disabled in the provider. | Clerk validates sessions; Open Door account APIs derive ownership from the authenticated user ID. Secret credentials remain server-side. |
| Replit PostgreSQL | Account saves, opt-in preferences, reward progress, lifecycle state, and corporate inquiries | Chosen saved-door details can include city and source interests; preferences store approved planning controls; progress stores door ID, tier, and category. Inquiry submissions store consented contact/project details. | Server-only parameterized queries. Account data is owner-scoped; inquiry reads/management require a server-verified admin role. Full journey and Lab history are not synced. |
| Qloo Hackathon API | Explicit live discovery using shared **Demo** or **Connect your own** | Search receives entered interest text and a requested entity type. Insights receives resolved Qloo entity IDs; location is included only for supported place/destination queries. Budget, time, movement, and energy preferences are not sent. | Fixed HTTPS hackathon host. Shared key remains server-only; personal keys are submitted to the server, held temporarily in process memory, and never returned or placed in browser/account storage. |
| Image hosts referenced by Qloo results | When a Live result contains an HTTPS image URL and the browser renders it | The browser requests the image from that URL, exposing ordinary network/browser request metadata to the image host. The app sends no referrer URL. | URL is restricted to HTTPS, but image hosting domains may vary. |
| Google Fonts | On page load, due to the stylesheet import in the UI | Font requests can expose ordinary network/browser request metadata to Google. No referrer URL is sent. | Cosmetic only; the browser falls back to system fonts if unavailable. |

Shared **Demo** uses live Qloo. **Try prepared examples** and `/demo` use deterministic authored examples and do not call Qloo. Guest saves, full journey state, feedback, opened-door browser history, and Discovery Lab branches are browser-local. Optional sign-in uses Clerk sessions and sends explicitly saved doors, opt-in preferences, and minimal reward events to account storage. Shared reward summaries contain earned badge/star details and the home-page URL, not saved interests or location. Maps and social links navigate to external sites; they are not map-data retrieval or an advertising integration.
